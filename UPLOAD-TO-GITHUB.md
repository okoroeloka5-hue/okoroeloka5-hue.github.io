# Upload guide for your existing GitHub repository

Your repository name is already correct: `okoroeloka5-hue.github.io`.

1. Download the portfolio ZIP.
2. Extract it. Open the extracted folder.
3. You should see `index.html`, `styles.css`, `script.js`, `content.js`, `assets/`, and `docs/` together.
4. In GitHub, open your `okoroeloka5-hue.github.io` repository.
5. Click **Add file**, then **Upload files**.
6. Drag all the items *inside* the extracted portfolio folder into GitHub. Select the files and folders, not the outer folder itself. Do not upload the ZIP file.
7. Confirm that `index.html` is in the root upload list, not inside `okoro-chukwueloka-portfolio/`.
8. Commit the upload to `main`.
9. Open **Settings → Pages** and set **Deploy from a branch → main → /(root)**.
10. Your site address will be `https://okoroeloka5-hue.github.io/`.

The current README in the repository can be replaced by the one supplied in this bundle. If you see an overwrite prompt, use the replacement option. The existing README is not needed by the website.

**Important:** Keep the folder structure inside `assets/` and `docs/` unchanged. The website uses those relative paths to display photographs, certificates, the WeChat QR code, and downloadable documents.
