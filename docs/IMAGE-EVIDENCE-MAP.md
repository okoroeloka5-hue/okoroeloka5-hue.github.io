## Presentation behaviour

All 60 indexed archive images are represented as `<img>` elements in the static HTML. Each gallery item has an image caption and an enlarge control that opens the image viewer. Project images are grouped with the relevant case study; the profile, field attachment, leadership, award and credential images are grouped with their corresponding personal-history sections. The design does not rely on an external JavaScript data source to render the galleries.
